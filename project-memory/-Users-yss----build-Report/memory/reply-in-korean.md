사용자에게 보내는 답변은 항상 한국어로 작성한다. 작업 보고, 결과 요약, 질문 모두 해당된다.

**Why:** 사용자가 영어로 작성된 결과 보고를 받고 "한글로 답변해줘야지"라고 지적했다 (2026-10-19).
**How to apply:** 긴 작업이나 백그라운드 작업을 마친 뒤의 최종 보고도 한국어로 쓴다. 코드, 경로, 고유명사는 원문 그대로 둔다.
