Where the rules live: `gemini-대화-주제별정리.md` has the hook collection in 4부 §12 and the format in 3부 부록 and 4부 §1. `gemini-대화-전체기록.md` (~2MB) has the raw turns; search it by turn number, don't read it whole.

Latest rules (cover style from turn #558, 2026-10-08):
- **Text:** 2 short lines. Line 1 white. Line 2 yellow with a **dark** outline. A red outline was the standard from June to early August, then changed to "짙은 테두리"; it can follow the product's tone (navy, brown, black). Each line ends with one emoji. Use a big, heavy gothic font (Pretendard ExtraBold).
- **Wording:** Apply the hook collection (#553). Its patterns: cost-saving ("돈 쓰기 전에 이 기준부터 보세요", "비싼 거 사지 말고…"), loss-aversion ("모르고 지나가면 손해/후회"), and reverse-thinking.
- **Hooks that worked for this account:** "~저만 몰랐나요?", "제발/절대 ~하지 마세요 ❌", "어디서 샀냐고 난리 난", hiding the product as "이걸로/이거", concrete numbers, calling out the target viewer, and FOMO.
- **Banned:** "끝까지 보세요", honest feature-list "홈쇼핑" phrasing, and exaggerated slang. The tone is friendly 해요체 and the person's own playful endings are welcome.
- **Background:** Never show the product alone and still on the first screen. Use a pain cut, a satisfying "solved" moment or action cut, or a before/after split.
- **Curiosity first (person's request, 2026-10-09):** Covers must make people as curious as possible. Don't hand over the answer. Pair a relatable pain with a hidden payoff, e.g. the pain shot on top and the result blurred under a big yellow "?" below, with the text pointing at it ("이렇게", "이거"). Keep the wording short and teasing (docs: "최대한 짧게, 미치도록 궁금하게").
- **Delivery:** Write 3 options, mark #1 as 가장 추천, and give a background-scene recommendation for each. Don't generate images unless asked.
- **Placement:** In the video, the cover is the first 4 frames (~0.13s). The person asked for **no [광고] label on the cover**; the label starts right after it. Also save the cover frame as a PNG in the work folder's `완성본/`.

**Why:** These come from the person's own Reels that did well. They complained when a cover ignored the hook notes (#559). They also had to re-ask for the docs check after a first pass only partly applied it (the red outline was outdated).

**How to apply:** Before writing or changing any cover, re-check these rules (and the docs if anything is unclear). In the reply, name the hook pattern and background type used.
