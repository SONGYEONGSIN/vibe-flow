운영부 업무 지식을 파일(옵시디언 볼트)로 관리하고, 에이전트가 그 지식으로 답하고 자동학습해 축적하는 것이 목표. 사용자가 참고 시스템(옵시디언 볼트 + Argo/Lean-AX 통합 지식망) 화면을 보고 착수.

**4개 서브시스템으로 분해** (한 덩어리로 하면 안 됨):
(a) 저장소 · (b) 열람 화면 · (c) 에이전트가 지식으로 답함 · (d) 자동학습·축적.
(a)(b)부터. (d)는 마지막 — 검증 없이 쌓으면 틀린 지식으로 답하고 그 답이 다시 쌓여 오류가 증폭된다.

**결정된 것** (2026-08-14):
- 볼트 원본 = 마크다운 파일, **SharePoint `운영부` 문서고 하위**. OneDrive 동기 폴더를 옵시디언 볼트로 연다
- **운영자 전원이 쓴다** (지정 작성자 없음) → 형식 강제 불가, 드러내는 3층위로(템플릿/인덱스 검사/미분류 표시)
- LLM 경로는 **Claude 구독 + Agent SDK, 회사 PC** (사용자가 API 권장을 듣고도 구독 선택)

**결정적 제약**: OPS-Console 레포는 **PUBLIC**. 사내 지식(고객사·사고 이력·단가·담당자)을 커밋하면 되돌릴 수 없어 볼트를 레포에 둘 수 없다. 이것이 SharePoint를 고른 이유.

**분류 (7개 + 제안)**: `개념 · 플레이북 · 규칙 · 결정 · 오류사례 · 엔티티 · 프로젝트` + `제안/`(에이전트 초안 전용).
- `상태`는 의도적으로 뺐다 — L1(Supabase)이 답할 것을 파일에 적으면 즉시 낡는다
- `규칙`은 2026-08-15 분류 실험이 요구해 추가했다(10개 중 3개가 "특정 대상에 대해 지켜야 하는 규칙"이라 어디에도 안 들어갔다)
- `규칙` vs `결정`을 가르는 말은 **주어** — 우리가 정했으면 결정, 외부 합의·도구 강제면 규칙

**볼트 실물** (2026-08-15 생성 완료): SharePoint `운영부/17. 업무 지식망`.
Graph item ID = `01TGOQVTSPG43PWBJZXZC3246PSGBLPKHP` (1단계에서 `SHAREPOINT_KNOWLEDGE_FOLDER_ID`로 사용).
**레포가 PUBLIC이라 이 ID는 레포 문서에 적지 않았다** — 여기(비공개 메모리)에만 둔다.
8개 디렉토리 + `_templates/지식.md`까지 Graph로 세워둠.

**현재 상태** (2026-08-16): **(a) 저장소 · (b) 열람 화면 · (c) 에이전트 연결까지 실운영**. 남은 건 (d) 자동학습뿐.
- 설계 문서 #982 / 인덱싱 잡 #983 / 열람 화면 #985 / 검색 연결 #988 / 본문 폭 #989 머지
- 인덱싱은 **10분마다 cron-job.org** → `/api/automations/run?jobId=knowledge-index`. 잡 등록은 `automations/registry.ts` 1줄, 조직도(`agent-org/registry.ts`)에도 `vault-indexer`로 넣어야 테스트가 통과한다
- 볼트에 문서 10건 — **전부 에이전트(내)가 쓴 것이고 사용자가 쓴 문서는 0건**. 그중 3건이 사실 오류로 걸러져 수정했다(30% 오류율, §8에 실측). owner는 사용자 지시로 전부 `송영신`이나 **깊이 검토된 건 2건뿐**

**설계 문서의 "문서 30건 이상일 때 어시스턴트에 연결"은 2026-08-16에 뒤집었다.** 근거가 "10건짜리 볼트를 붙여도 답이 나아지지 않는다"는 **내 추측**이었는데, 사용자가 실제로 검색해 보고 "안 나온다"고 한 게 더 나은 증거였다. 10건도 경위서 절차·공문대장 규칙처럼 실제로 묻는 종류다.

**알려진 한계 (검색 순위)**: 점수가 "본문 어디든 토큰이 나오면 1점"이라 **제목 일치를 우대하지 않는다**. `공문 시행번호는 어떻게 매겨져?`에서 제목이 그대로 일치하는 문서가 2등이다. 다른 도메인도 같은 방식이라 두었고, 문서가 늘면 여기가 먼저 티가 난다.

**아직 안 끝난 것**:
- 0단계의 **사람 분류 판정** — 운영자가 머릿속 지식을 직접 쓸 때도 7개 분류가 버티는지는 확인 안 됐다. 그게 0단계 완료 조건이다
- (d) 자동학습 — `제안/` + 사람 승인 게이트가 먼저다
- 인덱싱이 **하루 144행**을 `automation_runs`에 쌓는다. 다른 잡의 실패가 여기 묻히는지 지켜볼 것

**동기 관련 확인 사실** (내가 두 번 오진한 뒤 실측):
- 볼트 로컬 경로 = `~/Library/CloudStorage/OneDrive-진학사/Shortcuts/어플라이사업본부 - 17. 업무 지식망` (맥)
- **OneDrive `바로 가기 추가` 경로로도 양방향 동기 정상** — 추가·삭제 20~40초. "바로 가기라 안 된다"는 내 진단은 틀렸다
- 처음 "문서가 서버에 0건"이던 원인은 동기가 아니라 **편집이 파일에 반영 안 됨**(옵시디언은 내용이 실제로 바뀌어야 저장)
- **로컬 파일을 이 세션에서 직접 읽고 쓸 수 있다** — "저장 안 됨 vs 업로드 안 됨"은 앞으로 내가 바로 가린다
