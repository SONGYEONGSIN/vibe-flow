`/dashboard/postal` — **우편물 / 전도금** 두 탭. 영수증을 A4에 풀칠하고 등기번호를 손으로 엑셀에 옮겨 적던 일을 화면으로 옮겼다.

```
영수증 사진 → [추출] → 표 확인·수정 → [확정] → postal_items + 전도금 장부 한 줄
```

단계: 1 보관(#1027) · 2 판독(#1028) · 검토화면(#1029) · 전도금+연동(#1030) · 폴러 등록(#1031) · **3 등기대장 기록(#1048, `ledger-append.ts`/`ledger-write.ts`)**.
**원래 4단계 계획이었는데 3·4가 2단계에 흡수됐다** — 담당자 자동배정이 검토 화면에, 엑셀 기록이 전도금 반영으로.

## 판독 — Agent SDK 이미지 Read

API 키가 없어(구독 경로) Vercel에서 못 읽는다. **어시스턴트와 같은 구조**: 웹이 `postal_extract_requests`에 쌓고, 회사 PC 폴러(`scripts/postal/extract-local.mjs`, 어시스턴트와 **별개 프로세스**)가 claim해 서명 URL로 이미지를 임시 폴더에 내려받아 `Read`로 판독.

**실측(실제 종이 영수증)**: 10.2초, 접수번호·일시·등기 3건의 등기번호·요금·우편번호·수취인 **15/15 일치**. 카드정보 미포함. 정답을 먼저 손으로 적어두고 대조했다(순서를 반대로 하면 채점이 무의미).

**함정**: 모델이 `I'll open the receipt image first.`를 먼저 말하고 JSON을 냈다. 어시스턴트에서 얻은 "텍스트 블록을 모은다"가 **여기선 거꾸로 작용해** JSON이 깨졌다 → 앞뒤 말이 섞여도 `{`~`}`만 잘라 읽는다. [[claude-agent-sdk-hardening]] 5번의 반대 사례.

## 담당자 자동 배정 — 총괄장 대조

수취인 `우석대 강정화`에서 소속을 떼어 `02. 배정리스트`(3열 대학명, **13열 수시**) 또는 `03. 대학원`(1열, **7열 운영자**)을 본다.

**규칙 둘 다 실제 데이터로 검증했다**:
- **`대학원` 표기가 있을 때만** 대학원 시트. 두 시트에 다 있는 49곳 중 **40곳(82%)이 담당자가 다르다** — 임의로 고르면 82% 확률로 틀린다
- **`창원대` → 그 낱말이 바로 `대학교`로 이어지는 곳만**. 창원문성대는 사이에 낱말이 끼고, 폴리텍은 괄호 안이라 제외 → 국립창원대학교 하나로 좁혀진다
- **후보가 둘 이상이면 비워두고 후보만**(건국대 서울/글로컬). 자동으로 고르면 틀린 담당자가 조용히 들어가고 우편물이 엉뚱한 사람에게 간다

## 전도금 장부 — 엑셀에 쓴다

`08. 비용관리(인증,우편,전도금) > 전도금 > 2026년도 전도금 비용.xlsx`, 연도별 시트.
env `SHAREPOINT_PETTY_CASH_ITEM_ID`(Vercel 3환경 등록됨). **DB로 옮겨 담지 않는다** — 사람이 엑셀에서도 고치므로 복제하면 어느 쪽이 맞는지 모른다(총괄장과 같은 방침).

잔액 장부다. 청구 행(`전도금청구 | 남은돈 | 500,000`)과 사용 행이 섞이고, **금액 표기도 `" 3,920 "` 와 `"13290"` 이 섞인다**(손으로 적은 것 vs 붙여넣은 것).

**엑셀 쓰기는 되돌리기 어렵다.** 화면에서 지울 방법이 없고, Graph 워크북은 반영에 1~2분 걸려 직후 재조회로 성공 판정도 못 한다([[graph-workbook-session-persist-delay]]). 그래서 **쓰기 전에** 막는다:
- 중복 검사(같은 날짜·금액·건수) — 두 번 확정해도 장부는 한 줄
- **쓸 위치는 그때 시트가 정한다** — 우리가 센 행 수를 믿으면 사람이 그새 적은 줄을 덮어쓴다
- 잔액 못 읽으면 아예 안 씀
- **장부 쓰기가 실패해도 확정 자체는 살린다** — `postal_items`는 이미 저장됐고, 실패라 하면 사람이 다시 눌러 중복 저장된다

## 화면

탭은 **등기내역 / 전도금**. 페이지 제목이 이미 '우편물'이라 첫 탭까지 우편물이면 겹쳐 읽힌다(#1039).

**한 건도 없어도 목록의 모양을 지킨다** — 0건일 때 화면 전체가 문장 한 줄로 早期 반환돼 제목·검색창·표 머리가 통째로 사라졌었다. 검색은 원래 있었는데 그때 같이 없어져 "검색이 없다"로 보였다. 빈 안내는 표 안에 두고, **'한 건도 없음'과 '검색에 안 걸림'은 문구를 나눈다**(하라는 일이 다르다).

**금액은 `tabular-nums`** — `font-mono` 는 등기번호·경로처럼 한 글자씩 대조하는 값 전용. 우편물만 모노라 튀었다(#1036). 규칙은 `.claude/rules/design.md` 에 적혀 있다.

**삭제**(#1035): 확정건은 **admin 도 못 지운다** — 확정 시 전도금 엑셀에 한 줄이 들어가고 그건 화면에서 못 지우므로 근거가 사라진다. 권한이 아니라 순서의 문제라 버튼 자체를 안 보여준다. 반대로 **판독 중은 막지 않는다**(폴러가 꺼지면 '읽는 중'에서 영영 못 지운다 — 실제로 그 상태였다). 행을 먼저 지우고 스토리지 파일을 지운다(반대면 열리지도 지워지지도 않는 카드가 남는다).
