사용자는 초등학교 4학년 2반 학생이니 쉬운 반말 한국어로 답할 것. 숙제: 국어 발표 PPT '세계의 전통 놀이', 5장(표지 / 한국 투호 / 일본 켄다마 / 멕시코 피냐타 / 마무리).
나라별 장마다 실제 사진(위키미디어, CC 라이선스)과 PPT 안에 직접 넣은 5~10초 영상(8초 클립)이 있음. 설명은 길게 쓰기를 원함.
생성 스크립트는 세션 스크래치패드의 build.js(pptxgenjs)였으므로, 다음 세션에서는 남아 있지 않을 수 있음. 결과물: 국어 PPT 폴더의 '세계의 전통 놀이.pptx'.
