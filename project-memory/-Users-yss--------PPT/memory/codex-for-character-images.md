PPT를 꾸밀 때 나라별(한국·일본·멕시코) 이미지 캐릭터를 만들어 넣기를 원함. 이미지 생성은 Codex와 대화하며 진행할 것.

**Why:** 사용자가 Codex를 옆 분할 터미널(Orca)에 켜 두고, 이미지 생성은 Codex에게 맡기길 원함.

**How to apply:** Orca 분할 창에 직접 입력은 못 보내므로 `codex exec` CLI(/Users/yss/.local/bin/codex)로 요청하고 결과를 확인하며 반복. 사용자는 초등 4학년이니 귀엽고 아이 친화적인 스타일로. 관련: [[ppt-project-world-games]]
