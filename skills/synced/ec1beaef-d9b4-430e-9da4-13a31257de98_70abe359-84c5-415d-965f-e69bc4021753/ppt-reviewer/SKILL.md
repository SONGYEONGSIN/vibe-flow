# PPT 검수 비서 (3/3단계: 검수 + 규칙 진화)

파이프라인: ppt-planner(기획) → ppt-designer(디자인) → **ppt-reviewer(검수)**

두 가지 모드가 있다.
- **모드 A — 검수**: 완성된 덱을 점검하고 고친다
- **모드 B — 규칙 갱신**: 사용자가 고친 파일과 AI 원본을 비교해 디자인 규칙을 업데이트한다

---

## 모드 A. 검수

### A-1. 렌더링해서 눈으로 본다
- PPTX: PDF로 변환 → 장별 이미지로 만들어 한 장씩 확인
- HTML: 브라우저로 1280×720 스크린샷
- 코드만 보고 통과 판정 금지

### A-2. 체크리스트 (장마다)

**내용**
- [ ] 핵심문장이 결론을 담은 완결 문장인가 (명사형 제목 X)
- [ ] 핵심문장만 이어 읽어도 스토리가 통하는가 (덱 전체)
- [ ] 모든 수치에 출처가 있는가, 기획서와 수치가 일치하는가
- [ ] `[확인 필요]`가 남아 있다면 목록으로 보고했는가
- [ ] 불릿 5개 이하, 문장 2줄 이하

**레이아웃**
- [ ] 섹션 라벨·핵심문장·쪽번호가 모든 본문 장에서 같은 위치인가
- [ ] 좌우 여백 동일, 카드 간격 동일
- [ ] 콘텐츠 영역 하단 20% 이상이 비어 있지 않은가
- [ ] 텍스트가 카드·도형 밖으로 넘치거나 잘리지 않았는가
- [ ] 요소 정렬선이 맞는가 (좌측 끝, 상단 끝)

**AI 티 (슬롭) 신호**
- [ ] 강조색이 한 가지인가, 글로우가 장당 1개 이하인가
- [ ] 전폭 색 띠, 제목 밑줄, 왼쪽 굵은 세로선 카드, 이모지 아이콘이 없는가
- [ ] 모든 카드가 똑같은 크기로 나열된 '카드 벽'이 아닌가 (위계가 보이는가)
- [ ] 의미 없는 장식 도형·그라데이션이 없는가
- [ ] "혁신적인", "다양한", "효율적인" 같은 빈 수식어가 없는가
- [ ] 같은 종류 데이터의 차트 형식이 통일됐는가

**형식별**
- [ ] PPTX: 차트가 네이티브 차트인가 (더블클릭 시 데이터 편집 가능), 원본 xlsx 동봉
- [ ] HTML: 방향키 이동, 쪽번호, 1280×720 비율 유지
- [ ] 폰트가 지정 폰트로 렌더링되는가

### A-3. 보고와 수정
```
[검수 결과] 통과 N장 / 수정 N장
| 장 | 문제 | 수정 내용 |
[확인 필요 항목] ...
```
- 수정은 직접 반영하고 다시 렌더링해서 확인 (최대 2회 루프)
- 내용 판단이 필요한 문제(수치 불일치, 메시지 변경)는 고치지 말고 사용자에게 묻는다

---

## 모드 B. 규칙 갱신 (내가 고친 것 → 규칙으로)

트리거: 사용자가 "내가 고친 거야", "이렇게 되게 해줘"와 함께 수정본을 올릴 때.

1. AI 원본과 수정본을 장별로 비교한다 (위치·크기·색·폰트·문장·구조)
2. 차이를 **일반화 가능한 규칙**과 **이번 덱에만 해당하는 수정**으로 나눈다
   - 예: 핵심문장 32px → 28px로 줄임 = 규칙 / 3장 문구 수정 = 일회성
3. 규칙 후보를 표로 제시:
```
| # | 관찰한 변경 | 제안 규칙 | 반영 위치 (ppt-designer 절) |
```
4. 🚦 사용자가 채택한 규칙만, ppt-designer 스킬의 해당 절을 고친 **전체 SKILL.md 개선안**으로 제안한다 (부분 패치 X)
5. 기획 쪽 규칙(문장 스타일, 구조)이면 ppt-planner 개선안으로 제안한다

원칙: 한 번의 수정에서 규칙을 과하게 일반화하지 않는다. 같은 수정이 두 번 이상 나오거나 사용자가 "항상"이라고 하면 규칙으로 올린다.
